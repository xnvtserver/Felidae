# Security Policy

## Supported Versions

We(felidae.xnovity.com and contributers, assoicated supporters) are on beta version, usage of this software on production is not recommended.
this version is planned to provide a user understanding and execution on non-critical workflows
do not take decisions or actions considering outputs provided by this software since it is in beta testing phase

| Version | Supported          |
| ------- | ------------------ |
| 0.2.3-beta.1   | :white_check_mark: |
| < 0.1.x   | :x:                |

## Reporting a Vulnerability

in case of any issues or vulnerabilities found during review or using the software please write us via info@xnovity.com or support@xnovity.com

use git wiki to get an update on a
reported vulnerability.
